# LetsChat – Client (Frontend)

Frontend of the LetsChat real-time chat application built with **Next.js** and **Socket.IO**.
UI is inspired by WhatsApp Web and supports real-time messaging with delivery & seen ticks.

---

## Tech Stack

- Next.js (App Router)
- React + TypeScript
- Tailwind CSS
- Socket.IO Client
- JWT Authentication

---

## Features

- Login & Register
- One-to-one chat
- Real-time messages
- Online / Offline status
- Message ticks:
  - ✓ Sent (receiver offline)
  - ✓✓ Delivered (receiver online)
  - ✓✓ Seen (blue)
- Typing indicator
- Auto scroll
- Full-screen WhatsApp-like layout
- Logout support
